# External agent tooling: adopt-or-decline third-party harnesses, context managers and compaction stacks

## Context

Outside helpers keep appearing that promise to run the work, brief it, or
compress it, and each request deserves an answer measured against the method
rather than against popularity. When someone proposes a helper, the question is
whether it closes a gap already named, whether it runs inside the existing loop
rather than beside it, and whether everyone it lets act stays bound by the same
claim, permission and review discipline.

The two stories divide the question: one evaluates the named candidates against
those bars and keeps only the lesson worth taking — carrying lessons across
runs while discarding dead ends; the other transfers what the underlying
research actually found into the method itself. (ADR 0022.)

## Acceptance

Complete when both stories — the external-harness evaluation and the
harness-research transfer — are terminal and the product owner has recorded
acceptance on this epic. Nothing further is checked at this level.
