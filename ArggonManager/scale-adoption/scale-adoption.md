# "Scale adoption: views, agent loop, reporting"

## Context

Phase 1 shipped the convention and the CLI (`launch-mvp`). This initiative covers the next adoption curve, informed by how adjacent tools win daily use: Linear's saved views and filters, Backlog.md's MCP server / agent instructions / milestones, Taskmaster's next-action guidance, and Jira's hierarchy reporting. Three epics: `views` (find work fast), `agent-loop` (agents as first-class users), `reporting` (see progress at a glance).

## Acceptance

- [ ] Epic `views` done: filter language, saved views, local web board
- [ ] Epic `agent-loop` done: MCP server over the shared kernel, `next` + `instructions` commands
- [ ] Epic `reporting` done: read-only progress report, milestone design proposed for v3
- [ ] Convention changes go through ADRs; v0 validation stays green throughout
