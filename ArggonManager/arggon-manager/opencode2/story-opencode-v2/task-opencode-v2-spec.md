# Spec and plan: generated .opencode seam (config, agents, commands)

## Context

W1 of [plan-opencode2-009](../../../docs/plans/plan-opencode2-009.md)
(T2 + T3): the declarative OpenCode V2 seam. Per
[ADR 0010](../../../docs/adr/0010-opencode2-native-architecture.md) the seam
is generated by `arggon init`, zero-config for the adopter, never overwriting,
and free of rule duplication (prompts and permissions only, pointing at
`docs/agents.md` / `docs/engineering.md` / the `arggon-cli` skill).

## Acceptance

- [x] Spec `docs/specs/spec-opencode-seam-010.md`: purpose, invariants I1–I6,
      synopsis (template → destination table, marker styles, buckets),
      acceptance criteria; validates clean.
- [x] Invariants explicit: config generated only when the adopter has no
      OpenCode config (root or `.opencode/`); never-overwrite via the existing
      provenance machinery; JSON/JSONC valid without an HTML marker;
      frontmatter-first for agents/commands with the marker as a YAML comment.
- [x] Agent design mapped to the repo orchestration: coordinator (primary,
      subagent allow-list worker/reviewer/explore), worker (subagent, nesting
      denied), reviewer (subagent, `edit` denied).
- [x] Command design: `/arggon-next|start|done|handoff|status` as prompt
      templates driving MCP tools plus `/arggon-review`
      (`agent: arggon-reviewer`, `subagent: true`); no shell blocks with
      argument placeholders.
- [x] Plan `docs/plans/plan-opencode-seam-010.md` with ordered tasks T1–T5 and
      verifiable acceptance.
- [x] Spec and plan statuses flipped to `implemented` in this landing PR.
