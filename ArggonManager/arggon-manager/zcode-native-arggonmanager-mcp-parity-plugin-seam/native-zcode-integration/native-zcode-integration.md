# Native ZCode integration

## Context

ZCode is the second native client for ArggonManager (product-owner decision,
2026-09-28, mirroring the OpenCode V2 program in ADR 0010/0011). ZCode has no
code-mode tool API: its extension model is a declarative plugin (commands,
skills, hooks, mcpServers, agents) plus MCP as the only typed tool surface.
The seam is therefore split in two tracked tasks: full tool parity in
`arggon mcp` (task-mcp-full-surface) and the vendored plugin with commands,
agents and the reviewer hook backstop (task-zcode-plugin-seam). Architecture
decision: ADR 0014 (in this PR).

## Acceptance

- [ ] MCP exposes the full 15-tool surface (task-mcp-full-surface)
- [ ] ZCode plugin seam generated by `arggon init --full` with reviewer
      backstop (task-zcode-plugin-seam)
- [ ] ADR 0014 accepted and spec implemented
