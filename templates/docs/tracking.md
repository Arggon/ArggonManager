# Work tracking in {{PROJECT_NAME}}

This project tracks work **in-tree** under `tasks/` as Markdown work items (initiatives, epics, stories, tasks, bugs) managed by [`arggon`](https://github.com/Arggon/ArggonManager). GitHub is used for **PRs only** — please do not open GitHub issues.

- Find work: `arggon list --status todo --json`
- File new work: `arggon create task|bug "<title>" --parent <story-id>`
- The layout and frontmatter schema live in `tasks/.convention.yml` and, if present, [`docs/convention.md`](convention.md).
